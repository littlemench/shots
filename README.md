# Shots

A simple, joyful way to showcase and explore photography: filter by album, place, camera, type and colour, and download full-resolution photos with easy credit.

Built for one photographer first, and open source so others can run their own.

- `design/`: brief, gallery prototype, logo and type explorations
- `site/`: what's published at [shots.photography](https://shots.photography). Build it with `python3 tools/build_site.py`

Status: early prototype.
